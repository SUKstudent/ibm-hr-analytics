# IBM HR Analytics — Employee Attrition Analysis

## Project Overview
This project explores employee attrition using the IBM HR Analytics Employee Attrition dataset. The goal is to understand employee attrition patterns and examine how attrition varies across departments, overtime status, and job satisfaction levels.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab
- Power BI
- GitHub

## Project Workflow
1. Loaded and inspected the dataset.
2. Checked data types, missing values, and duplicate records.
3. Performed exploratory data analysis (EDA).
4. Compared attrition across departments, overtime status, and job satisfaction levels.
5. Created visualizations and summarized key findings.
6. Built a Power BI dashboard for interactive exploration.

## Key Findings
- The dataset contains 1,470 employee records and 35 columns.
- Overall employee attrition rate is 16.12% (237 employees).
- The Sales department has the highest attrition rate among the three departments at 20.63%.
- Employees working overtime have a higher attrition rate (30.53%) than employees not working overtime (10.44%).
- Employees with job satisfaction level 1 have an attrition rate of 22.84%, compared with 11.33% for level 4.

## Data Quality Checks
Initial checks found no missing values or duplicate rows. These results are documented as data quality checks; no additional cleaning is claimed unless explicitly performed.

## Project Files

- `IBM_HR_Analytics.ipynb` — Python notebook containing data inspection, EDA, visualizations, and findings.
- Power BI dashboard (`.pbix`) — interactive dashboard for exploring employee attrition.

## Conclusion
The analysis identifies differences in employee attrition across departments, overtime status, and job satisfaction levels. These patterns may help guide further investigation into employee retention. The observed associations do not establish causation.
